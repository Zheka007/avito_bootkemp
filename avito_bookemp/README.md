# Детекция ботов-парсеров Авито

Для каждой куки модель выдаёт `score` от 0 до 1 — вероятность того, что это сервис сбора данных.

**Результат на валидации:** P@R0.7 = **0.76905** (константный ответ — 0.09391).

## Запуск

Python 3.14, зависимости — `pip install -r requirements.txt`.
Данные лежат в `data/`, рядом `metric.py`. Ноутбуки запускаются по порядку:

1. `analysis_and_features.ipynb` — анализ данных и признаки → `train_features.csv`, `test_features.csv`
2. `train.ipynb` — обучение и сабмит → `submission.csv`

Сиды зафиксированы (`random_state=42`).

## Решение

**Очистка данных.** Оставлены только события внутри окна наблюдения, удалены дубликаты,
события отсортированы по времени, написание платформы приведено к одному виду.

**Признаки (22 на куку):** тайминги событий, доли типов действий, глубина поиска,
разнообразие объявлений, категорий и городов, координаты курсора на web, возраст куки.

**Модель:** среднее вероятностей CatBoost и XGBoost. Гиперпараметры XGBoost подобраны
через `GridSearchCV` с разбиением по времени.

**Валидация:** по времени — первые 80% дней для обучения, последние 20% для проверки,
так как test идёт по датам после train.

## Что нашлось в данных

- У ботов интервалы между событиями короче и ровнее, чем у людей.
- Web-боты водят курсор в узком окне: координата X почти не выходит за ~1260 px, у людей — до 1920.
- Боты глубже листают выдачу и обходят больше городов при меньшем числе категорий.
- Много ботов на совсем новых куках (0–1 день).
- У ботов в train много событий после конца окна, но в test таких событий нет, а по условию их брать нельзя, поэтому они выброшены.

## Эксперименты

| | 14 признаков | 22 признака |
|---|---|---|
| CatBoost | 0.463 | 0.700 |
| LightGBM | 0.464 | 0.694 |
| XGBoost | 0.507 | 0.751 |
| CatBoost + XGBoost | — | **0.794** |

Главный прирост дали новые признаки, а не выбор модели. Подбор гиперпараметров почти ничего не изменил.
В валидации ~220 ботов, поэтому разница в 0.01–0.03 между моделями может быть случайной.

## Библиотеки

pandas, numpy, matplotlib, scikit-learn, CatBoost, LightGBM, XGBoost.
Всё работает локально, без внешних API и языковых моделей.
